# Graph That Motion Simulation

Interactive 1D Kinematics and Graph Matching Simulation for high school physics, built for **The Thinking Experiment (PhysicsKit)**.

## 🚀 Features
- **11 Canonical Kinematic Motions:** Covers Position-Time ($x$-$t$) and Velocity-Time ($v$-$t$) graphs including multi-stage and turnaround motions.
- **PER-Aligned Motion Maps:** Ticker tape dots with vertical clustering/stacking for stationary states.
- **Synchronized Playhead:** Live glowing tracer dot on graphs synchronized to physical car motion.
- **Time Scrubber & Slow-Mo:** Full temporal control with vector overlays ($\vec{v}$ and $\vec{a}$).
- **Diagnostic Feedback Engine:** Conceptual feedback on misconceptions rather than generic error banners.
- **Prediction Sketching Mode:** Active learning drawing canvas for students to sketch predictions prior to viewing options.
- **Custom Scenario Builder:** Visual builder for designing multi-stage motions with custom acceleration and velocity parameters.
